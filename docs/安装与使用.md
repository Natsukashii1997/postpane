# 驿窗安装与使用说明（给第二个人照着做）

照着这份，在另一台 Mac 上从源码装起驿窗，接上 Claude Code 和 ChatGPT，跑通一次「Claude 做完 → ChatGPT 审 → 自动转回 Claude」。走完请填最后的复现记录表。

**先读三条限制**

- 仓库是私有的，要常浩给你 GitHub 访问权限。
- 侧栏里的 Clawd 小人素材版权归 Anthropic，装好的应用只能自己用，不能转发或公开。
- 只在 macOS 上验证过。Windows、Linux 的构建入口有，但没跑通过。

## 1. 准备环境

| 要装的 | 怎么确认 |
|---|---|
| Xcode 命令行工具 | `xcode-select -p` 有输出 |
| Node.js 24 或更新 | `node -v` |
| pnpm（仓库锁定 11.22.0） | `corepack enable` 后 `pnpm -v` |
| Rust 稳定版（rustup） | `source ~/.cargo/env; rustc -V` |
| GitHub CLI，已登录 | `gh auth status` |
| Google Chrome，已登录 chatgpt.com | 接 ChatGPT 才需要 |
| Claude Code，在 `/usr/local/bin/claude` | 图形界面应用找的是这个路径，nvm 里的那份它找不到 |

## 2. 建签名证书（只做一次）

打包时用登录钥匙串里名叫 `PostPane Local Signing` 的证书签名（`src/apps/desktop/src-tauri/tauri.macos.conf.json`）。没有这张证书，打包会报找不到身份。

```sh
mkdir -p ~/postpane-cert && cd ~/postpane-cert
cat > ext.cnf <<'EOF'
[req]
distinguished_name = dn
x509_extensions = ext
prompt = no
[dn]
CN = PostPane Local Signing
[ext]
basicConstraints = critical,CA:false
keyUsage = critical,digitalSignature
extendedKeyUsage = critical,codeSigning
EOF
openssl req -x509 -newkey rsa:2048 -nodes -days 3650 -config ext.cnf -keyout key.pem -out cert.pem
openssl pkcs12 -export -inkey key.pem -in cert.pem -name "PostPane Local Signing" -out pp.p12 -passout pass:pp
security import pp.p12 -k ~/Library/Keychains/login.keychain-db -P pp -T /usr/bin/codesign
```

`security find-identity -v` 不列出它是正常的（证书没设信任），签名照样能用。这几步 2026-11-07 在 macOS 自带的 LibreSSL 3.3.6 上用临时钥匙串验证过，能签名。

## 3. 克隆、构建、安装

```sh
gh repo clone Natsukashii1997/postpane && cd postpane
source ~/.cargo/env
pnpm install
node src/tooling/package-resources.mjs      # 生成打包资源，新克隆必须先跑
pnpm run check                              # 可选：格式、类型、构建、边界检查
pnpm --filter @agent-hud/desktop exec tauri build --bundles app
```

- 打包用 `--bundles app`，不要用 `--bundle`：生成 DMG 时会自动启动应用。
- 产物在 `target/release/bundle/macos/PostPane.app`。安装前先退出正在运行的驿窗，再复制过去：

```sh
osascript -e 'quit app "PostPane"'
ditto target/release/bundle/macos/PostPane.app /Applications/PostPane.app
open /Applications/PostPane.app
```

**要多久、占多大**：2026-11-07 在常浩的 Mac 上，照第 3 步从 GitHub 新克隆一份（`4a1785c`）实走了一遍：克隆 11 秒，`pnpm install` 20 秒，`package-resources.mjs` 约 10 分钟（编译打包要带的程序，最慢），`pnpm run check` 3 分 17 秒，打包 9 分 42 秒，合计约 24 分钟。四步全部退出码 0，产物 107.6 MB，签名是 `certificate leaf = H"b773068e…"`。`target/` 占 3.0 GB，`node_modules` 312 MB；装完可以 `cargo clean` 收回。日志在 `~/Library/Application Support/postpane/evidence/2026-11-07-second-person/`。这一遍没装进 `/Applications`，免得覆盖常浩在用的那份；而且这台机器上本来就有签名证书，所以第 2 步「没证书会怎样」没有实际验证。

**第一次启动**：系统会弹「"PostPane"想访问"文稿"文件夹中的文件」，点「允许」。不点的话，设置页会一直显示「正在读取本机活动…」，侧栏也不出现（LESSONS L-06）。以后用同一张证书重装，就不会再弹。

## 4. 接上 Claude Code

1. 打开驿窗的设置，进「智能体插件」页，在 Claude Code 一行点「安装」。
2. 已经开着的 Claude Code 会话里执行 `/reload-plugins`；新开的会话会自动加载。
3. 回到侧栏：Claude 的额度、正在运行的会话、审批和提问应该都能看到。

## 5. 接上 ChatGPT（接力要用）

1. Chrome 打开 `chrome://extensions`，打开「开发者模式」，点「加载已解压的扩展程序」，选仓库里的 `src/apps/chrome-extension/`。插件 id 固定为 `fjjbgamejbdjdaddinacpbmaeokinbjl`。
2. 驿窗设置 →「智能体插件」→「ChatGPT（Chrome 插件）」一行点「登记」。这一步会写入 `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.postpane.chatgpt.json`。
3. 在 Chrome 里打开并登录 chatgpt.com，设置页那一行显示已连上，就接通了。

## 6. 跑一次接力

1. 在一个 Claude Code 会话里做完一件事（比如一个 PR），然后对它说：「用驿窗的 `relay_to_chatgpt` 把这一轮交给 ChatGPT 审」。工具说明里写了 brief 要带哪六项。最后一项是请 ChatGPT 在回信最后一行写「结论：通过」或「结论：需修改」，没有这一行，驿窗不知道下一步怎么走。
2. 驿窗会在 Chrome 里新开一个 ChatGPT 对话，把 brief 发进去。侧栏出现一张接力卡，展开能看到每一步。
3. 自动往返默认开着：
   - 回「需修改」且审查预算没用完（工程审查按风险级：L1 审 1 轮，L2、L3 最多 2 轮，不填按 2 轮）：自动转回原来的 Claude 会话去改，改完 Claude 再交回来；L1 用完这 1 轮后转回 Claude 改完就收口，不再复审；
   - 回「通过」：把回信（含 P2、P3 等非阻断意见）转回原来的 Claude 会话，写明这是终局、不用再送审，然后接力结束；
   - 预算用完、没写结论、认不出审查出口（同一个 PR 的审查跨会话累计，用完后要你明确授权，Claude 才能再送一次）：同样把回信转回 Claude 会话，写明交你决定，然后自动往返停下，等你决定；
   - 30 分钟没回信、ChatGPT 会话打不开：自动往返停下，卡上出现「等你决定」，由你点「继续自动」或「重试」（这两种目前不通知 Claude 会话）；
   - 转回时如果 Claude 会话已经结束：这段话会排进那个会话的待发送队列，你在 Claude 里打开那个会话，它就接着做；排了 1 小时没人领，才交还给你。
4. 驿窗重启后，所有自动往返先暂停，要你在卡上点「继续自动」。
5. 每一步都记在 `~/Library/Application Support/app.postpane.mac/chatgpt/handoffs.json`。查法见 [L5 运行记录](evidence/L5-运行记录.md)「怎么查」。

## 7. 出问题先看这里

| 现象 | 原因与办法 |
|---|---|
| 打包报找不到签名身份 | 第 2 步没做，或证书名字不对 |
| 设置页一直「正在读取本机活动…」 | 「文稿」权限弹窗没点（L-06） |
| 接力卡「转回 Claude」报「这个会话还没加载插件」 | 多半是 Claude 会话已经结束了，不一定真的没加载（L-14）；在 Claude 里打开那个会话就行 |
| 手写设置文件后数据服务报错 | 设置文件里必须有 `"providers": {}` |
| ChatGPT 一直不回 | 看 Chrome 里那个 chatgpt.com 标签页是否还开着、是否登录 |
